# User stories

The team wrote user stories for the analytics requirements and built one report per story. Examples of the format used:

- As an analytic team member, I want to access and analyse grade data for all primary grade students across all XYZ Institute campuses, so that I can identify areas for improvement in the curriculum.
- As an analytic team member, I want to access and analyse grade data for all female students across all XYZ Institute campuses, so that I can identify areas for improvement in the curriculum.

The same pattern was used for pre-primary, secondary and higher grades and for male students.

> The full backlog was tracked in Excel during the internship and is not published.
